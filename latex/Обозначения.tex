\section*{ОБОЗНАЧЕНИЯ И СОКРАЩЕНИЯ}

ИС -- информационная система.

ПИС -- программно-информационная система.

ИТ -- информационные технологии. 

ПО -- программное обеспечение.

РП -- рабочий проект.

ТЗ -- техническое задание.

ТП -- технический проект.

ЯП -- язык программирования.

ИИ -- искусственный интеллект.

НС -- нейронная сеть.

СВ -- сверточная вычислительная сеть.

CV -- компьютерное зрение (Computer Vision).

GUI -- графический пользовательский интерфейс (Graphical User Interface).

API -- интерфейс прикладного программирования (Application Programming Interface).

CNN -- сверточная нейронная сеть (Convolutional Neural Network).

ML -- машинное обучение (Machine Learning).

DL -- глубокое обучение (Deep Learning).

IoU -- коэффициент пересечения областей (Intersection over Union).

FPS -- количество кадров в секунду (Frames Per Second).

GPU -- графический процессор (Graphics Processing Unit).

CPU -- центральный процессор (Central Processing Unit).

YOLOv8n -- модель обнаружения объектов семейства YOLO восьмого поколения.
